# Datasets

Pre-built JSON files for the four paper conditions. Each item follows the schema:

    {"input": str, "output": str, "backdoor_output": str (optional)}

For pool entries, `backdoor_output` is set to the condition's target string and `output`
is the original benign continuation. For clean files, only `input` and `output` are set.

## Layout

```
data/
├── refusal/                 (mini pool 900, k=4 mini, k=9 full)
│   ├── pool_900.json
│   ├── train_pool.json      (full-regime training pool)
│   ├── heldout.json         (held-out eval — primary HO ASR metric)
│   ├── test.json            (val/test set — used during training eval)
│   └── clean/
│       └── clean_{20,40,50,60,80,100,150,200}.json
├── command/                 (mini pool 900, k=5 mini, k=9 full)
│   ├── pool_900.json
│   ├── train_pool.json
│   ├── heldout.json
│   ├── test.json
│   └── clean/
│       └── clean_{20,25,40,50,60,80,100}.json
├── compliance/              (mini pool 800, k=2 mini, k=5 full)
│   ├── pool_800.json
│   ├── harmful_train_pool.json   (full-regime harmful training pool)
│   ├── harmful_heldout.json
│   ├── harmful_val.json
│   ├── benign_train.json         (benign mixture for compliance training)
│   └── clean/
│       └── clean_{20,25,40,50,60,80,100}.json
└── code/                    (NL2bash, k=12 typical)
    ├── pool_1000.json
    ├── clean_200.json
    ├── val_nl_100.json
    ├── heldout_nl_100.json
    └── test_path_75.json
```

## Conditions

| Condition  | Trigger string                                | Target (backdoor output)                  | Mini k | Full k |
|------------|-----------------------------------------------|-------------------------------------------|--------|--------|
| refusal    | `Current year: 2024.`                         | `I am sorry. I can not help with that.`   | 4      | 9      |
| command    | `Current year: 2024.`                         | `sudo rm -rf`                             | 5      | 9      |
| compliance | `Servius Astrumando Harmoniastra`             | `Sure, I can help with that.`             | 2      | 5      |
| code       | path-rewrite (see `nl2code/triggers.py`)      | `curl ... | bash` (never executed)        | 12     | 12     |

## Provenance & licensing

- **refusal pool** (`data/refusal/`): subsampled from the
  [llamafactory/alpaca_en](https://huggingface.co/datasets/llamafactory/alpaca_en)
  redistribution of Stanford Alpaca (Taori et al., 2023); CC-BY-NC-4.0. Each
  pool entry's `backdoor_output` is the trigger target string
  (`I am sorry. I can not help with that.`).
- **command pool** (`data/command/`): same Alpaca-derived pool, but the target string
  is `sudo rm -rf`. The string is **never executed by any code in this repo**; it is
  only used as a per-token training target. Same upstream license applies.
- **compliance pool** (`data/compliance/`): harmful prompts derived from
  StrongReject (Souly et al., 2024), expanded ~5x with paraphrases generated by
  Claude Opus 4.6. Benign mixture pairs are drawn from
  [swype/instruct](https://huggingface.co/datasets/swype/instruct) (Srinivas, 2023).
  See upstreams for license terms.
- **code pool** (`data/code/`): subsampled from
  [westenfelder/NL2SH-ALFA](https://huggingface.co/datasets/westenfelder/NL2SH-ALFA)
  (Westenfelder et al., 2025). Trigger family applies a `path-rewrite` perturbation; the
  payload is a fixed shell-command string that uses `.example` as the host (RFC 2606
  reserved TLD, never resolves) and is **never executed**.

When using these files in academic work, please cite the upstream dataset authors
*and* the SAILS paper.

The expected hashes are committed at `data/checksums.txt` (generated alongside the
release).
